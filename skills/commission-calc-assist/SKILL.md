## 能力描述

按排班与核销核算技师提成

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `params` | object | ✅ | 测算参数（成本、售价、费率等） |

## 输出规格

测算与评估

- `result`：关键结果数值，标注单位
- `breakdown`：逐项拆解
- `assumption`：所用假设；关键参数变动时结果如何变化

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 调用示例

**输入**：

```json
{
  "params": "轻语SPA滨江店 技师王丽 2026年9月提成核算（2026-10-08由店长发起）：当月核销记录——① 精油SPA 60分钟，单价298元，核销12次，全部来自美团渠道；② 足部推拿45分钟，单价168元，核销20次，门店散客；③ 小气泡深层清洁，单价128元，核销8次，微信小程序渠道；④ 当月成功销售储值卡1张，面值5000元。",
  "rules": "门店提成制度（2026年8月版）：① 精油SPA类按项目收入15%提成；② 推拿类按项目收入12%提成；③ 清洁护理类按项目收入10%提成；④ 储值卡销售按卡面值3%提成；⑤ 美团渠道订单按订单收入5%扣除渠道扣点（从技师提成中扣减）；计算结果保留两位小数。"
}

```

**输出**：

```markdown
## 结果

技师王丽 2026年9月应发提成合计 **1013.20 元**（人民币；含渠道扣点扣减，为测算草稿值）。

## 测算明细

| 项目 | 计算式 | 结果 | 说明 |
|---|---|---|---|
| 精油SPA 60分钟提成 | 298元 × 12次 = 3576.00元；3576.00 × 15% | 536.40元 | 12次核销均来自美团渠道，计提基数按全额订单收入 |
| 足部推拿45分钟提成 | 168元 × 20次 = 3360.00元；3360.00 × 12% | 403.20元 | 门店散客，无渠道扣点 |
| 小气泡深层清洁提成 | 128元 × 8次 = 1024.00元；1024.00 × 10% | 102.40元 | 微信小程序渠道，制度中仅美团订单扣点，此处不扣减 |
| 储值卡销售提成 | 5000元 × 1张；5000.00 × 3% | 150.00元 | 按卡面值计提 |
| 美团渠道扣点 | 3576.00元 × 5% | -178.80元 | 仅对美团渠道的精油SPA订单扣减，从提成总额中扣除 |
| 合计 | 536.40 + 403.20 + 102.40 + 150.00 − 178.80 | 1013.20元 | 应发提成草稿值 |

## 假设与敏感性

1. 假设提成基数按订单全额收入计算（未剔除优惠券、平台补贴的分摊）；若门店以客户实付金额为基数，各项计提及扣点需按实付口径重算。
2. 假设储值卡3%提成不随客户后续消耗退卡而追回；若存在退卡追回条款，150.00元需按实际退卡情况调整。
3. 敏感性：美团扣点每上调1个百分点，合计减少35.76元；精油SPA提成比例每上调1个百分点，合计增加35.76元。
4. 本结果为涉及资金的测算草稿，仅供核算参考，须由店长/财务人工复核确认后方可进入工资表。

—— AI 生成内容，需人工复核 ——


```
