# 智能排班引擎

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_local_05_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 排班调度师 |
| 能力族 | — |
| 复杂度 | `L` |
| 阶段 | `P1` |
| 复用度 | 低（行业专用） |
| 资产形态 | SOP 深度提示词 + 只读连接器说明（无平台写权限、无 API Key） |

## 能力描述

多资源（人/房/设备）排班与冲突检测：把待排预约单按「指名优先 → 期望时段 → 提交
顺序」排进「技师 × 房间 × 时间」三维时间轴，逐单核对班次/午休培训段/15 分钟消毒
缓冲/末单红线（闭店前 60 分钟），冲突当场检出并给出复检零冲突的改派候选，输出
每位技师利用率（>85% 超负荷 / <30% 可补单）。排班表经店长确认后下发。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `items` | array | ✅ | 待处理的条目列表 |

## 输出规格

排期与调度

- `schedule`：逐项时间安排
- `conflicts`：时间/资源冲突及处理方式
- `unscheduled`：受约束无法安排的条目

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）
