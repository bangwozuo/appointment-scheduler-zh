# appointment-scheduler-zh 上座率热力与低谷行动口径

对每个时段，周容量=工作日容量×5+周末容量×2，实际营业天不同则按营业日历显式改算；源50人次仅demo，不是所有门店固定容量。上座率=该时段实际人次÷该时段可比周容量；容量0不能相除。源档位为<60%低谷、60%–85%正常、>85%满负荷，85%本身属于正常，保留分子分母及单位。

下周时段预测=上周实际×周环比系数，并给±15%经验带；环比、舍入和区间基数以当前受验工具输出为准，不冒充统计置信度。不同容量时段的总体利用率应按总实际/总容量，不能无条件算各时段百分比均值。缺历史或容量时不推促销效果。

低谷触达骨架为前一天10:00、老客与次卡人群、微信优先/短信兜底，仍服从资格、共享每日2条频控及静默。动作与价格方案经老板确认；无渠道时只输出not_sent计划。周一触发需实际注册与运行回执，流程文件本身不证明定时已生效，不承诺低谷填平或营收增加。
