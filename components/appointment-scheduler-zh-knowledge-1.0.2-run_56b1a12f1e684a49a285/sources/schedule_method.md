# appointment-scheduler-zh 多资源约束排位与冲突复检规则

源技能优先级为指名优先→期望时段→提交顺序；每个候选同时检查技师技能与班次、休息培训、对应房型和设备占用、服务时长、15分钟消毒交接缓冲及末单规则。源给闭店前60分钟开始末单，但“前”的等号与服务/缓冲是否必须闭店前结束须按具体流程和本店配置明确；缺项不自行接受边界单。

所有改派候选必须重新跑相同约束，记录冲突资源、原时段、变更原因和需客户确认的内容。利用率注明分子是服务时长还是含缓冲占用、分母是净可服务工时还是总班次；源>85%超负荷、<30%可补单只能在同口径下判断，不以阈值代替硬约束。

原示例存在技师技能未提供、冲突描述与11:15改期时间不一致等问题，不作为已验证排班oracle。时段粒度及在线/冲突检测流程的时延要求各自保留；设备边界和不明确时刻进入待核列表。方案经店长确认不等于已写入预约系统；无写权限只交候选表。
