# appointment-scheduler-zh 提醒时机与触达排期规则

源提醒规则分别保留：次日预约在前一天15:00–16:00排提醒；到店前30分钟提醒；高风险前2小时二次确认，中风险前30分钟提醒；周报低谷活动的触达骨架为前一天10:00。21:30–09:00静默段顺延，但若顺延后已过预约或失去提醒意义，列unscheduled，不能机械顺延后称可执行。

同一客户每日最多2条，所有流程共享当天计数与原通知幂等键，不各自各发2条。渠道按资格和许可选择，源为微信优先、未关注才短信，示例中同一对象混用渠道需按当前配置复核，不能把示例覆盖主规则。每份文案包含当前预约事实及真实改期/取消入口。

候补一空位一人、30分钟无确认才按轮转顺延；先查原通知回执，避免超时重复通知。所有文案与排期由老板核对、前台执行；本地排期只标planned/not_sent。风险标签仅内部使用，不把“高风险”发送给客户，不加入源示例要求的诱导返现话术。
