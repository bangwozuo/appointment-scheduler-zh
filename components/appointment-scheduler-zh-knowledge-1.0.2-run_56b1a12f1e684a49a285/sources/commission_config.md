# appointment-scheduler-zh 客户提成制度与核销数据

提成制度模板字段：store_id、policy_id/revision、effective_from/to、approved_by、项目品类费率、渠道扣点、计提基数gross/paid、优惠券/补贴归属、储值卡按面值或实收、舍入策略、退卡追回规则和币种。业务记录逐行保存技师、核销ID、日期、品类、渠道、收入、售卡面值及原单位置，排班记录不等于已核销收入。

执行先用有效期筛制度，再对账核销与收入；缺费率、基数或退卡规则时明确缺项，不从源示例默认15%、5%、3%。制度变更按生效区间分别计算，不能把月底制度套全月。结果是待店长/财务核对的测算，不自动进入工资或转账。

自造模板行：SIM-P01、品类X、收入100元、品类费率10%、渠道扣点2%、人民币、按全额、无售卡；这些仅仿真输入，不是实际门店制度。客户实收凭据、优惠券分摊及退卡仍需独立配置。

## 原资产定位

若门店以客户实付金额为基数，各项计提及扣点需按实付口径重算。
