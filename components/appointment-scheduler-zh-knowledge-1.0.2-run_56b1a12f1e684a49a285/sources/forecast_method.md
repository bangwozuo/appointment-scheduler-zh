# appointment-scheduler-zh 星期均值预测与经验区间解释

原方法按星期几分组计算历史实际核销均值，再乘趋势系数，向未来7个日期逐日映射；趋势未提供时源默认+3%，必须在assumption明确“源方法缺省”，不冒充本店已观测增长。少于7天拒绝外推；有缺失日期或某星期无样本时列缺口，不把缺失补为0。历史口径为实际核销且不含取消，样本范围由实际资料决定，不强凑180天。

±15%是经验区间，不能称统计置信区间或95%概率；上下限应按实际脚本的趋势与舍入顺序复算，并说明是否在趋势后的中心值计算。总量必须由本次逐日结果汇总，不能抄原演示：原文本区间合计与逐行区间存在不一致，保留为待纠正案例，不作为oracle。

节假日、营销、天气和容量变化单列未建模因素，不把源示例中的国庆效应当每周固定因素。自造7天每一天实际10单、趋势显式0时中心值应各10；原件脚本和经验带舍入仍须定向验收后才能对外给结论。
