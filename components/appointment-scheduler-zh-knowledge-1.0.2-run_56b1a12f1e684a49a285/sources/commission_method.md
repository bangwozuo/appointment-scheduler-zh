# appointment-scheduler-zh 提成拆解与敏感性计算口径

逐项目计提额=该项目计提基数×该品类比例；渠道扣减额=适用渠道收入基数×渠道扣点；储值卡提成=制度指定卡面值或实收×售卡比例。合计=项目计提和+售卡提成和−渠道扣减和。逐行保留原核销单、基数、单位、比例、舍入前值及两位小数展示；采用逐行舍入还是汇总舍入必须跟制度一致，不能凭模型默认。

敏感性把“1个百分点”换为0.01；某品类费率上调1个百分点影响为该品类基数×0.01，扣点上调则总额减少该渠道基数×0.01，售卡费率同理。其他参数不变并单独展示影响，不把1%相对变化混作1个百分点。

自造100元收入、10%品类率、2%渠道扣点对应项目10元、扣减2元、净8元；品类率上调1个百分点净额增加1元。此为独立算式示例，运行数值仍须使用当前受验脚本原件；实付基数、补贴与退卡追回未核不能称应发工资。
