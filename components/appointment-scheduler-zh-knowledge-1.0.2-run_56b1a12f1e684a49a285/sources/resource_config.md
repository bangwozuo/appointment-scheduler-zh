# appointment-scheduler-zh 门店人员项目房间设备配置

资源配置为版本化门店资料：技师ID与项目技能矩阵、可服务房型、工时与偏好、班次起止、休息培训区间；项目ID、服务时长、价目和所需设备；房间ID、房型、数量与不可用时段；设备ID、共享容量与可用区间；营业日历、闭店时间、缓冲策略、生效日期及来源位置。技师有班次不表示具备任意项目技能。

约束区间与设备规则缺失时列待确认，不自行给设备无限容量。按当前快照核已占用、维修及版本；排班建议以同一版本复检，期间资源变更需重算受影响预约，不能用旧“零冲突”覆盖新快照。不同流程粒度、缓冲和最后开单规则分别登记，不能隐式统一。

自造配置可用SIM-T1一名技师、SIM-R1一间房、10:00–18:00班次及60分钟项目，明确并非原客户资料；若两个请求共用一台设备，设备容量未给时不称可同时安排。没有门店写接口时只输出待确认排班，不直接占用资源。

## 原资产定位

技师技能矩阵与工时偏好；历史预约与爽约记录（预测模型燃料）；项目时长标准库。
